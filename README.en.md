# VibeLand

> In the vibe-coding era, bring all your scattered projects back into one place.

[中文](./README.md) · 🔗 [vibe-land.c01dkit.com](https://vibe-land.c01dkit.com)

## What is this

VibeLand is a **personal project index portal**.

When you spin up projects vibe-coding style, the code scatters across different machines, servers, and folders: a little tool on this laptop, a site on that VPS, a half-finished repo somewhere else… Before long you can't even remember where a given project's code lives, what its repo URL is, or whether it ever shipped.

VibeLand pulls them all into **one private index** — a space that's just yours, where every project is visible at a glance.

## What you can track

- Project cards grouped by **category** for an instant overview
- Each project's **code location, Git repo, server, and live URL**
- **Intro / dev log / plan** (written in Markdown)
- **Screenshots**, tags, status (in-dev / live / archived), and pinning

## Private & secure

Sign in with Google — **your data is visible only to you**, never shared across accounts.
